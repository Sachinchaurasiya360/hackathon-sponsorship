# Contributing to Hackathon Sponsorship List

Thank you for helping make this resource better for hackathon organizers everywhere.

## What to Contribute

- **New sponsors** — companies you've successfully gotten sponsorship from
- **Direct links** — working URLs to application forms, credit programs, or DevRel contacts
- **Corrected info** — broken links, wrong tier labels, outdated contact emails
- **Resources** — guides, blog posts, or tools useful for hackathon organizers

## How to Contribute

1. Fork this repository
2. Make your changes in `README.md`
3. Open a Pull Request with a short description of what you added/changed

## Sponsor Entry Format

For the Tier 1 table (with direct apply links):
```markdown
| **Company Name** | Description of what they offer | [program-name](https://link.com) |
```

For the flat list:
```
Company Name — Sponsor Type (e.g., Gold Sponsor / Technology Partner / In-Kind)
```

## Link Guidelines

- Only add **verified, working links** — check the URL before submitting
- Prefer direct program pages over company homepages (e.g., `company.com/hackathons` > `company.com`)
- Include a contact email if you have one (only if it's publicly listed)
