# Hackathon Sponsors List (Open Source)

This repository contains a **public sponsor & partner list** that hackathon organizers can use to reach out for:
- Sponsorship (cash / prizes)
- Cloud credits / tools
- Swags / goodies
- Mentorship / community support
- Security audits / Web3 support
- Registration / platform partnerships

⚠️ **Note:** Sponsorship decisions depend on event size, location, audience, and timing. Always send a clear proposal and follow up politely.

## How to Reach Out (Quick Steps)

1. Find the right person:
   - Developer Relations (DevRel)
   - Community Manager
   - Partnerships / Sponsorship Team
   - Marketing / HR (for hiring-focused hackathons)

2. Send a short intro:
   - Hackathon name + date
   - Expected participants
   - What you want (cash / credits / swag)
   - What they get (branding + hiring + visibility)

3. Follow up:
   - After 2–3 days
   - Again after 6–7 days (final follow-up)
